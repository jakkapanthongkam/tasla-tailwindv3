# Tesla TailwindCSS Vue

This project clones parts of Tesla's landing page using Vue 3 and Tailwind CSS.

## Development

1. Install dependencies
   ```bash
   npm install
   ```
2. Generate Tailwind CSS
   ```bash
   npm run build:css
   ```
3. Start a dev server
   ```bash
   npm run serve
   ```

## Build

To build the production bundle run:

```bash
npm run build
```

The compiled files will be output to the `dist/` folder.
