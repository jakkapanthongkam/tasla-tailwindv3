# Tesla TailwindCSS Vue CLI

This project uses Tailwind CSS and Vue 3 via Vue CLI.

## Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Build Tailwind CSS in watch mode:
   ```bash
   npm run build:css
   ```
3. Start the dev server:
   ```bash
   npm run serve
   ```

The generated CSS file `public/output.css` is used by the Vue application.
